# 全球覆盖的后续工作

已完成配置的 100 所大学与 7 家科技企业的 Wikidata 全部队列返回及人物事实采集。后续继续围绕来源覆盖推进，不再用新增学校名字补榜单行数。

1. 以 ROR 遍历全球大学、研究院与研究机构，处理学校、院系、研究所、附属医院及沿革的归并层级。
2. 逐机构适配官网目录、公开 API、官方个人主页和 CV，建立完整名单分母，而不是把 Wikidata 当成完整 faculty 名册。
3. 扩展教职、研究员、博士后、访问、兼职、荣休、留职与联合任职的时间证据，完善当前职位子集。
4. 继续处理 ORCID / Wikidata / 机构身份关联与同名消歧；缺失字段保留未知。
5. 增加官方奖项名单、重要科技企业在职人员来源和独立 IEEE Milestone 机构事件；过去任职不算在职。
6. 提供机构覆盖与失败报告、按学科与年代的敏感性分析、规模归一化与不确定性。
7. 持续扩大有真实关系的图，再计算和展示 Top 100；不能用采集未完成的机构零节点制造名次。
