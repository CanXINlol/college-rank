# 交付验证（2026-10-23，Australia/Melbourne）

## 实际完成的公开源采集

- 配置的 100 所大学均已完成 Wikidata 任职队列的完整返回；另采集并核对了 7 家科技企业的机构 ID。
- 去重发现 258,245 个人物 ID；人物事实批次 1,034 / 1,034 完成，最终失败批次 0。
- 公开语料 239,326 份；其中 236,984 份有教研职业分类（包含历史人物和历史任职）。
- 有效参与计算的机构 7,171 个、机构关系 55,036 条。
- 博士层级教育记录 101,191 条；本科 51,399 条；硕士 39,274 条；未注明层级 134,849 条不计分。
- 映射 960 个有隶属/继承来源的机构实体，保留源机构与映射链；不合并已经采集的独立大学。
- 企业官网正面确认当前任职 3 人，并保存引用与来源哈希。这个子集不代表企业完整名册，其有效加分按参考人数缩放。

## 验证

- 20 项 Python 测试通过：认可方向、概率守恒、重复/联合任职、未知/候选排除、历史和当前区别、空值节点、失败不发布、学院归并不吞并独立大学。
- 8 项 Node 测试通过，包括完整发布语料的 Python / JS 全部机构排名、分数与人数一致性，以及人物分片中的真实 HTTPS 引用。
- 静态导出、gzip 输入和按需引用分片已生成；全部 100 个榜单行都有有效关系或附加贡献，未使用零证据机构补齐。
- 当前回合没有可用的浏览器自动化工具，因此没有把之前试验版截图作为本次大数据版视觉验证。
